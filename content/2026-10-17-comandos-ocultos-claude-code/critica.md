# Informe del Crítico Ciego

## Paso 1 (en frío)

- **De qué trata:** 4 comandos y atajos nativos poco conocidos de Claude Code (`/rewind`, `/context`, `/security-review` y `.claude/commands/`) para retomar el control de una sesión en terminal sin reiniciar de cero.
- **Tesis en una frase:** No necesitas cerrar la terminal cuando Claude Code se desvía o llena la memoria: sus comandos nativos permiten rebobinar código y contexto juntos, vigilar tokens, auditar seguridad y crear atajos en Markdown.
- **Qué haría:** enviar (a compañeros de equipo o canales de desarrollo).
- **A quién se lo mandaría:** Al colega que cierra la terminal cada vez que Claude comete un error o que se queja de costos de tokens.

---
